Getting Started

WeaversCanvas is a comprehensive tool for creating weaving drafts. It consists of four main components that work together to define a complete weave structure:

  • Threading — Which warp threads (ends) connect to which shafts
  • Tie-Up — Which shafts are lifted by which treadles
  • Treadling — Which treadles are pressed in which order (weft picks)
  • Main Drawdown — The resulting weave pattern (warp over weft or weft over warp)

The Grid Area

The main workspace shows four linked draft areas:

Threading (top row)

Shows which shaft each warp thread (vertical end) is tied to. Click any cell to cycle through shafts 1-8 (or set number of shafts in controls).

Tie-Up (middle row)

Matrix showing which shafts are lifted by each treadle. Click any cell to toggle lift/no-lift for that shaft-treadle combination.

Treadling (left column)

Shows which treadle is pressed for each weft pick (horizontal row). Click to cycle through treadles.

Main Drawdown (center)

The actual weave structure — white = warp shows over weft (warp-up), dark = weft shows over warp (weft-up). Click cells to manually add/edit pattern.

Drawing Tools

Use the tools panel on the left to draw patterns:

  • Point Tool — Click individual cells to toggle
  • Line Tool — Click and drag to draw lines
  • Freehand Tool — Draw freely like a brush
  • Select Tool — Select area to move/copy
  • Fill Tool — Flood fill an area

Toolbar Reference

Document Section

  • Clear All — Clear entire draft
  • Reset Default — Reset to default 48×48, 8 shafts, 10 treadles

View Section

  • Show Back — View underside of weave
  • Cloth View — Photographic weave preview: round shaded threads, cast shadows at every crossing, and true over/under interlacement. Combine with Show Back to flip to the underside.
  • Hide Rulers — Toggle ruler display
  • Undo/Redo — Reverse/repeat actions (Ctrl+Z / Ctrl+Y)

Generate Section

  • Randomize — Generate random pattern with density controls

Tools Section

  • Yarn Library — Browse 480+ yarns from the Master Yarn Chart 2014 and apply them to Sett Advisor or Yarn Calculator
  • Yarn Calc — Yarn calculator & cost estimator
  • Sett Advisor — Recommended EPI/sett guidance
  • Tools ▼ — Dropdown with:
    • Library — Save/load patterns
    • Analysis — Pattern analysis tools
    • Draw Tools — Advanced drawing
    • Pattern Tools — Transformations
    • Workflow — Project planning
    • Practical — Production notes
    • Notes — Freeform notes
    • Colour Tools — Color management

Output Section

  • Export WIF — Export in WIF format (Weaving Include File)
  • Import WIF — Import a WIF file
  • Print — Print/save PDF of draft
  • Export & Share — Export as PNG, PDF, or shareable link

Project Section

  • Save — Save project to file
  • Load — Load saved project

Controls Bar

  • Cell Size — Zoom in/out (10-40px)
  • Quick Sizes — 16×, 24×, 32×, 48× presets
  • Dimensions — Warp, Weft, Shafts, Treadles steppers
  • Color Palette — Click to change colors

Color Palette

The palette starts with 3 colors (blue, purple, burgundy) plus a + button to add more. You can have up to 6 colors at a time. Click any color to select it, then click on warp/weft color strips to apply. Double-click a swatch to edit its color; right-click to remove it. A fresh palette of 3 colors is restored whenever you press Clear All or Reset Default.

Keyboard Shortcuts

  • Ctrl+Z — Undo
  • Ctrl+Y — Redo
  • Ctrl+S — Save project
  • Delete — Clear selected

Export Formats

  • WIF — Standard weaving format compatible with most weaving software
  • PNG — Image at your chosen resolution
  • PDF — Full draft with all sections
  • Tileable PNG — Seamless repeating pattern

Yarn Calculator

Calculate yarn requirements and project cost:

  • Enter fabric dimensions (width, length)
  • Enter EPI (ends per inch) and PPI (picks per inch)
  • Input yarn length per cone/spoon and price
  • See calculated total yardage, number of cones, and estimated cost
  • Use the green Use This Pattern button to apply the current draft's EPI/PPI to a fresh project
Tip: Combine with Yarn Library — pick a yarn from the library and apply it here in one click.

Sett Advisor

Get recommended sett (EPI) based on:

  • Yarn type (cotton, wool, silk, etc.)
  • Yarn weight/thickness (WPI — wraps per inch)
  • Weave structure (plain, twill, satin, etc.)

Use the Common Yarn Weights preset dropdown to jump to a standard WPI (6, 8, 10, 12, 16, 22, 28, 40, 60, or 80 WPI). Selecting a preset auto-applies the WPI and recalculates the recommendation.

Tip: Use the Yarn Library's Use for Sett button to load a yarn's WPI in one click.

Yarn Library

The Yarn Library is a searchable catalog of over 480 yarns from the Master Yarn Chart 2014, built directly into the app. It is the fastest way to pick a yarn and have it pre-loaded into either the Sett Advisor or the Yarn Calculator.

Opening the Library

Click the 📚 Yarn Library button in the header's green tools group. The modal opens on top of the main workspace.

The Catalog

Each yarn is shown as a compact card displaying:

  • Name — the yarn's brand or generic name (e.g. "8/2 Cotton", "Cottolin", "Silk Noil")
  • Fiber dot & badge — a small colored dot indicates the fiber type (16 fibers total, color-coded), with the fiber name in a pill badge next to it
  • Yards per pound — the standard yardage metric used by weavers
  • Recommended sett — typical EPI range, shown only when the chart lists one

Toolbar

  • Search box — type any part of a yarn's name to filter the grid in real time (case-insensitive)
  • Family filter — narrow the catalog, or pick ⭐ Favorites (always at the top of the list) to show all yarns with your favorites sorted to the top
  • Count badge — shows how many yarns match the current search and filter (e.g. "12 of 487", or "3 favorites · 487 shown" when in Favorites mode)

Favorites

Every card has a small star button at the end of the title (right side, same line as the yarn name). Click it to mark a yarn as a favorite (the star turns gold ★); click again to un-favorite (☆). Your favorites are stored in the browser's local storage, so they persist between sessions on the same computer and browser.

To find your favorites, pick ⭐ Favorites from the family filter. Only your favorited yarns are shown — everything else is hidden.

Applying a Yarn

Each card has one or two action buttons at the bottom:

  • Use for Sett — opens the Sett Advisor with the yarn's typical WPI loaded. The yarn is then handled the same as if you had entered the WPI by hand.
  • Use for Yarn Calc — opens the Yarn Calculator with the yarn's typical EPI and PPI loaded, ready to size a project.

If a yarn in the chart has no listed sett, the corresponding button is disabled (greyed out) so the input is never pre-filled with a blank.

Workflow tip: The most common flow is: pick a yarn in the Library → Use for Sett to confirm a sett → Use for Yarn Calc to size the project → start drafting.
Data note: The library is sourced from a printed reference chart. Yardages and setts are typical ranges for each yarn; always confirm with the actual yarn in hand before warping a full project.

Tips & Tricks

  • Use Randomize with low density values for subtle patterns
  • Use Undo/Redo liberally — they're free!
  • Save your favorite patterns to the Library
  • Use Cloth View to preview the final result
  • Export as Tileable PNG for fabric mockups
  • Use the Yarn Library as the starting point for any new project — picking a yarn first often clarifies the rest of the design decisions

Features

WeaversCanvas includes the following features:

🎯 Threading Draft
Define which warp ends connect to which shafts (1-32 shafts supported).
🔗 Tie-Up Grid
Define shaft-treadle connections for lift mechanics.
↔ Treadling
Set the weft sequence (which treadles to press per pick).
🧵 Main Drawdown
The resulting weave pattern (warp over weft or vice versa).
📸 Cloth View
Photographic preview of your weave — round shaded threads, cast shadows at every crossing, true over/under interlacement, and instant Show Back flip.
⚡ Instant Resizing
Warp, weft, shaft, and treadle steppers respond instantly at any grid size — patterns and colours are preserved as the grid grows.
🖌 Drawing Tools
Point, Line, Freehand, Select, and Fill tools for pattern creation.
🎲 Randomize
Generate random patterns with adjustable density controls.
🎨 Colour Palette
Customizable warp and weft colors with harmony generator.
🧶 Yarn Calculator
Calculate yarn requirements, EPI, and cost estimates.
📐 Sett Advisor
Get recommended sett based on yarn type and weave structure.
📚 Yarn Library
Browse 480+ yarns from the Master Yarn Chart 2014; apply directly to Sett Advisor or Yarn Calculator.
📊 Analysis Tools
Identify weave structure, find repeats, check floats.
📤 Export & Share
Export WIF, PNG, PDF, tileable patterns, or shareable links.
🗂 Project Save/Load
Save and load projects locally or to browser storage.
↩ Undo/Redo
Full history with undo and redo (Ctrl+Z/Y).
🔀 Pattern Tools
Flip, rotate, invert, tile, and transform patterns.
